The Agency is a collection of agent personas you install as subagents, organised into divisions such as engineering, design, marketing, product, testing and support. Each agent is a Markdown file describing an identity, a mission, a working process, concrete deliverables and how it measures success, so activating one changes how your harness approaches the work, not just its tone.

It began as a Reddit thread and grew into a large community project. A desktop app browses the roster and installs agents into Claude Code, Codex, Cursor, Gemini CLI and other harnesses, or you can copy the files you want by hand.

**When to use it:** you want ready-made specialists instead of writing subagent prompts yourself, you need a starting point to adapt for your own team of agents, or you want to see how others structure agent roles.

**Caveats:** quality and depth vary across a roster this size, and the personalities are part of the design, which not everyone wants. Install only the agents you'll actually call; dozens of unused ones just add noise.
