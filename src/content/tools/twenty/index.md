Twenty is an open-source CRM in the mould of Salesforce, built for teams that want to shape it themselves. It has the usual pieces: companies, people and opportunities, table and kanban views, email and calendar sync, dashboards and a visual workflow builder. Custom objects and fields can be added in the interface, or written as code in a Twenty app that you version, deploy and publish like any other project.

AI is part of the product rather than a plug-in. A chat assistant answers questions about your records, and agents run multi-step jobs inside workflows, such as enriching records, drafting follow-ups or flagging deals at risk, with no more access than the user or role they act for. Every workspace, cloud or self-hosted, also serves an MCP endpoint. For coding agents, the project ships skills, also packaged as a Codex plugin, for creating, deploying and publishing Twenty apps, plus one that connects an agent to a workspace's MCP endpoint to read and summarise records.

**When to use it:** you want a CRM you control and can self-host, your team would rather extend its CRM in code than through settings screens, or you want a coding agent to build on or query your CRM.

**Caveats:** self-hosting means running and upgrading a full application with its database and job queue; the cloud version avoids that. It's a general-purpose CRM with AI features, not one built around an agent, and agents that act on customer data need their roles and permissions set with care.
