Mobbin is a reference library of interfaces from shipped products: screenshots of mobile and web apps, organised into single screens, multi-step flows and website sections, and searchable by pattern, by UI element or by the text on screen. Designers use it to see how established products handle a paywall, an onboarding flow or a settings page before drawing their own, and can save references to collections or copy them into Figma.

Its MCP server brings the same library to your agent. The agent searches screens, flows and website sections in plain language and gets back images, product names and links to the source pages, so a request like "design a paywall" can start from what real products already do. You connect it by signing in to your Mobbin account rather than pasting an API key.

**When to use it:** before you have an agent build a common screen or flow and want it grounded in patterns that already work, or when a design decision is stuck and you want to compare how several products solved it.

**Caveats:** it's a commercial service, and MCP access depends on your plan. It shows what other products did, not whether it worked for them, so the agent's suggestions still need your judgement, your brand and your accessibility requirements.
